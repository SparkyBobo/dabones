# DaBones

DaBones is a Halloween animatronic rock show project combining mechanical characters, embedded electronics, lighting control, audio playback, and stage effects.

The goal is to create a repeatable live Halloween performance experience where animated characters perform as a band with synchronized movement, lighting, and effects.

## Project Status

Current release:

**DaBones v1.0 — Halloween 2026**

The focus of v1.0 is a complete, reliable show experience.

The goal is not to complete every possible feature. Future enhancements are intentionally deferred into later releases.

## System Overview

DaBones consists of several integrated systems:

* Animated characters
* Mechanical motion systems
* Embedded controllers
* Lighting and DMX control
* Audio and MIDI synchronization
* Stage infrastructure
* Special effects

## Engineering Approach

The project follows a release-based engineering model:

* Define the release before building
* Capture design decisions and tradeoffs
* Separate ideas from commitments
* Document why decisions are made
* Build platforms that support future expansion
